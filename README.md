# Lokesh Panditi — Portfolio

High-integrity embedded systems, bare-metal firmware, and safety-critical avionics & defense architectures portfolio of **Lokesh Panditi**.

## Featured Projects

- **[Glyph](https://lokeshpanditi.vercel.app/glyph)** (`v1.1.0`): Portable, framebuffer-based graphics framework in Ada 2022 for resource-constrained microcontrollers (RP2040, SSD1306, ILI9341).
- **[Radio_Kit](https://lokeshpanditi.vercel.app/radiokit)** (`v1.0.0`): Bare-metal RF signal generation framework in Ada 2022 leveraging RP2040 clock-generation hardware with dual-core AMP and ChaCha20 encryption.
- **[MeshOS](https://lokeshpanditi.vercel.app/meshos)** (`v1.0.0`): Lightweight, fault-tolerant mesh networking system for ESP32 devices utilizing ESP-NOW, NimBLE, and PSA Crypto.

## Tech Stack & Tooling

- **Languages**: C (Advanced), Ada 2022 (Intermediate), Python (Intermediate), AArch64 Assembly (Beginner)
- **Platforms**: Raspberry Pi RP2040, Espressif ESP32
- **Protocols & Hardware**: UART, SPI, I²C, CAN, ESP-NOW, BLE / NimBLE, FreeRTOS, HAL
- **Development**: Vite, HTML5 / CSS3, Modern Web APIs

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

Production output will be generated in `dist/`.
