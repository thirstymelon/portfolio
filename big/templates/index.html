About

A short note on how I work — and why the lowest layer matters.

I'm Lokesh (Loki), an embedded systems developer who prefers registers to abstractions. My work lives at the boundary where software commands hardware directly — no OS buffer, no managed runtime.

I build reusable firmware components, distributed MCU networks, and software that runs reliably on bare silicon. I believe understanding a system at its lowest level is the only way to truly master it.

Building embedded frameworks in Ada 2022 for bare silicon targets, including Glyph (published on Alire) and Radio_Kit (transceiverless RF carrier synthesis) for the RP2040 (Vicharak Shrike-Lite).

Published on Alire Ada 2022 · Alire

Glyph Graphics Framework

A lightweight, zero-allocation embedded graphics framework written in Ada 2022 for bare-metal systems, published on the Alire package manager. Built with Liang–Barsky line clipping, Bresenham rasterization, and a hardware-independent framebuffer design on the RP2040 (Vicharak Shrike-Lite) and SSD1306 OLED.

Selected work

PROJECT 01 Published on Alire

Glyph Graphics Library

An open-source, zero-allocation embedded graphics framework written in Ada 2022 for bare-metal systems, published on the Alire package manager. Glyph provides hardware-independent rendering primitives (Liang–Barsky line clipping, Bresenham rasterization, static framebuffer canvas) verified on the Vicharak Shrike-Lite (RP2040) with an SSD1306 OLED.

PROJECT 02 ESP-NOW · 2.4 GHz

MeshOS Mesh

A decentralized, multi-hop communication platform built around ESP32 nodes, ESP-NOW, and native iOS and macOS companion applications — operating completely offline with P-256 ECDH and hardware-accelerated AES-128-GCM encryption.

PROJECT 03 RP2040 · Ada 2022

Radio_Kit Framework

An experimental Ada radio framework for the RP2040 that synthesizes programmable 6 Hz to 90 MHz RF carriers directly from native on-chip fractional clock dividers — operating without a dedicated external transceiver or oscillator chip across GPIO21, GPIO23, GPIO24, and GPIO25.
